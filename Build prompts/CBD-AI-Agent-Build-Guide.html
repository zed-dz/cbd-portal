DAY 1
Foundation + First Build
2–3 hours · All on Lovable.dev
  1. Open Lovable.dev → New Project
    Name it "CBD Operations Portal". You'll see a chat window on the left and a live preview on the right. This is where all your build work happens.
  2. Open your CBD portal HTML file
    Open CBD-Plant-Labour-Portal-v3.html in a text editor (Notepad on Windows, TextEdit on Mac, or VS Code). Select All → Copy Everything.
    ⚠️ The file is large (~750KB). On mobile, use a file manager app to open it. On desktop this is easiest.
  3. Paste Prompt #1 into Lovable chat
    Go to the Prompts tab in this guide. Copy Prompt #1 exactly. Paste it into the Lovable chat. Then immediately paste your entire HTML file contents below it in the same message. Hit Send.
    ✓ Lovable will take 10–15 minutes to process this. Do not type anything else until it finishes.
  4. Check the live preview
    Lovable gives you a preview URL. Open it. Check all 10 screens: Dashboard, Workers, Timesheets, Clients, Payroll, Messages, Licence Agent, Allocations, Client Approvals, Pending Workers. All should look identical to your HTML.
    ⚠️ If anything looks wrong, describe it in the Lovable chat. E.g. "The sidebar logo is not showing — fix it." Lovable will correct it.
  5. Connect Supabase to Lovable
    In Lovable → Settings → Supabase. Paste your Supabase Project URL and Anon Key. Lovable will auto-create all database tables based on the data structures in your HTML. Confirm in your Supabase dashboard that tables were created.
  6. Build Airtable tables (for Zapier automations)
    In Airtable → CBD Operations base → Create these tables with exact field names from the Env Vars tab: Workers, Timesheets, Allocations, Certifications, Clients, Messages_Log. The Zapier Zaps will write to these.
    ✓ Supabase = your app's live database. Airtable = Zapier's working database. They sync via Zapier.
  7. Push to GitHub + Vercel
    In Lovable → Settings → GitHub → Push to GitHub. Then in Vercel → New Project → Import from GitHub → Select your Lovable repo → Deploy. You now have a live URL like cbd-portal.vercel.app.
  8. Save your Vercel URL
    Write down your Vercel URL. You'll need it for Xero developer app setup and for all Zapier webhook URLs.

    Builds the API route that runs at 5:30 PM every day. It finds all timesheets with status = "submitted" and for each one: generates a signed approval token, sends an SMS via Twilio to the site manager, sends an HTML email via Resend with Approve/Dispute buttons.

    Builds the /approve/[token] page. Site manager receives this URL in their SMS/email. They tap it on their phone — no login needed. They see the worker, hours, site, date and tap Approve or Dispute. 24-hour countdown timer visible. After 24 hours — auto-approve cron runs.

    When site manager taps Dispute — a simple form appears asking for the reason. On submit: dispute reason saved to Supabase, timesheet status = "disputed", admin (Matt) receives immediate SMS alert on 0413 962 001.

    Set up Zap 4 (timesheet submitted → approval SMS/email), Zap 5 (site manager approves → Airtable update), Zap 6 (dispute → SMS to Matt), Zap 7 (24hr auto-approve). See the Zaps tab for full details.
